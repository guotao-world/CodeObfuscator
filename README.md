# 代码混淆工具使用说明

## 1. 输入文件准备

- 将输入文件放在 **`src_dir`** 文件夹里
- 工具会自动识别文件夹内的 `.c` 和 `.h` 文件
- ⚠️ 其他类型文件未做识别处理，可能会输出错误类型
- 直接运行 `exe` 即可

## 2. 选择配置文件

- 运行 exe 后，出现选择配置文件路径的提示
- 如果没有输入新的路径，将采用默认的配置文件 `whitelist_config.ini`（路径为 `..\whitelist_config.ini`）
- 输入新的配置文件路径时，**以 exe 所在文件夹为准**
- 配置文件包含以下内容：
  - 定义类型
  - 白名单文件
  - 白名单函数

## 3. 确认配置内容

- 选择配置文件后，会打印该配置文件中识别到的内容
- 并询问是否继续添加

## 4. 开始混淆

- 添加完毕后，将直接运行

## ⚠️ 重要提示

- 输出文件会自动创建一个命名为 **`dest_dir`** 的文件夹
- 会输出一个命名为 **`compare_file.txt`** 的过程文件，包含原文件命名 → 新文件命名的替换对照表
